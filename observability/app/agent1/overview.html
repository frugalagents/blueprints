The problem

Different frameworks. One execution to explain.

Agent telemetry differs in structure, semantics and capture coverage. Consolidation requires conversion into OTel, propagated causal context, and central processing while retaining source evidence.

Inspect all three services →
1. Different representations

A emits OTel; B exposes SDK-native tracing; C exposes LangChain callbacks. Supported instrumentors map source semantics into OTel.

2. Missing causal connections

Session and workflow IDs group activity. Recorded OTel parents and links establish which call caused which execution.

3. Claims are not evidence

Model text cannot prove a refund. Trusted tools check policy decisions; A verifies committed synthetic DB state.

What standardization buys us — and what it still requires

Common transport and identities. Explicit source semantics.

Source integration

Instrumentors / adapters must capture actual operations and preserve native identity. Missing source data cannot be recreated centrally.

OTel contract

Standard trace / span IDs, parents, links and service identity; documented extensions for workflow and verification.

Central processing

Collector applies common payload policy and known semantic mappings. New formats may require additional mappings.

Evidence checks

Generic inspector discovers services and compares supported identity, context, usage, status and verification fields.

Evidence and limits

Native and source OTel captures retain full synthetic content. Collector cleaning removes named prompt / tool payload fields; it is not a general PII scrubber. Versioned policies and trusted tool / DB verification provide prototype governance evidence.

LangChain native records come from real runtime callbacks. No LangSmith SaaS export import is implemented. Arbitrary vendor-native formats still require supported instrumentors or source adapters.

Preservation checks cover documented fields, not every optional semantic attribute. B SQL operations and uncaptured activity remain gaps. Only completed spans export; worker startup is included in HTTP duration without its own span.

Connected now displays all discovered services and uses the generic preservation checks. Older workflows may contain only A/B; a failure may stop execution before C.

No production HA, durable application retry, scalable storage or end-user access control is demonstrated. A trace without workflow context anywhere is stored but is not selectable in the workflow picker.
